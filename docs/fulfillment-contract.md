# Защищённая выдача персонального PDF · контракт V1

**Статус:** бизнес-логика и офлайн-тесты. НЕ работающий магазин и НЕ интеграция ЮKassa. Платежи выключены.

## Уже есть в develop

- server/order-domain.mjs: серверная цена 550.00 RUB, валидация даты и проверка успешного платежа.
- server/report-job.mjs: создание задания только после подтверждённой оплаты.
- server/fulfillment.mjs: достаёт заказ из доверенной БД; самостоятельно запрашивает платёж у провайдера; проверяет metadata.order_id; делает эксклюзивную попытку генерации; сохраняет PDF приватно; выдаёт подписанную ссылку только после авторизации.
- scripts/fulfillment.test.mjs: подмена суммы, чужой ID, неверная валюта, отсутствие доступа, повторные и одновременные запросы.

## Обязательные правила для настоящего сервера

1. Клиент никогда не задаёт цену. Сервер фиксирует 550.00 RUB.
2. Вебхук служит только сигналом для проверки; успешность подтверждается отдельным аутентифицированным запросом к ЮKassa.
3. Сверять payment.id, metadata.order_id, статус succeeded, paid=true, сумму и RUB; платёжный ID был заранее закреплён за заказом сервером.
4. Захват задания claimReport реализовать как атомарный compare-and-set с lease и fencing token. Прототип описывает контракт, но не заменяет реальную БД.
5. При прерывании процесса повторное выполнение должно быть безопасным; закрытые файлы нельзя делать публичными.
6. Клиент аутентифицируется отдельно от номера заказа; подписанные ссылки на PDF живут не более 300 секунд.
7. При возвратах и отменах прекращать новые выдачи, обновив доверенное состояние заказа.
8. Полная редакционная библиотека, генератор V3, изображения обложки и готовые PDF не хранятся в публичном GitHub.
9. Российские данные и контакты покупателей требуют надлежащей обработки, защиты, хранения и удаления.
10. Защита от массовых запросов и алерты о лимитах ставятся перед дорогими операциями; бесплатный калькулятор полностью работает в браузере.
11. Исходный серверный код не привязан к Netlify или Yandex Cloud. Реальные адаптеры провайдера, базы, закрытого генератора и хранилища ещё требуется внедрить.

## Схема

Браузер -> сервер заказов -> ЮKassa (оплата)

Уведомление -> отдельная проверка платежа -> проверенный заказ -> атомарная очередь -> закрытый генератор -> приватный PDF

Браузер -> авторизованный запрос -> подписанная ссылка -> приватный PDF
