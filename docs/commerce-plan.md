# План коммерческого запуска Матрицы судьбы

**Статус 21 октября 2026:** приём оплаты выключен. Это техническое задание для следующего этапа.

## Продукты
- Бесплатно: интерактивный калькулятор, краткие значения позиций, PDF-образец на 3 страницы.
- За **550 ₽ без подписки**: полный персональный отчёт. Целевой объём 25–35 страниц, только после проверки методики и редакционной базы.
- Символические нумерологические интерпретации не обладают доказанной предсказательной точностью.

## Как устроим оплату
1. Пользователь рассчитывает матрицу и выбирает полную версию.
2. Сервер создаёт уникальный заказ с заданной на сервере ценой 550.00 RUB и статусом pending. Нельзя доверять цене из браузера.
3. Сервер создаёт платёж через официальный API платёжной системы с ключом идемпотентности. Покупатель оплачивает на защищённой странице провайдера.
4. После уведомления сервер независимо подтверждает платёж у провайдера (в случае ЮKassa: статус succeeded, paid=true, 550.00 RUB, верный ID заказа). Повторные уведомления не должны дублировать выдачу.
5. Только подтверждённому заказу сервер формирует и выдаёт индивидуальный отчёт в PDF.
6. PDF хранится в приватном хранилище, доступен только покупателю по временной ссылке. Предусмотрены повторная доставка и возвраты.
7. Платная библиотека интерпретаций и ключи платёжного сервиса не хранятся в публичных исходниках GitHub, HTML или JavaScript клиента.

## Где размещать сервер
Netlify остаётся витриной. Для персональных данных российских пользователей необходимо отдельно проверить требования к локализации и выбрать соответствующий хостинг/БД (не считать серверы Netlify в РФ по умолчанию). Секреты вводить только в защищённых настройках соответствующей платформы, не присылать в чат.
