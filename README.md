# Матрица судьбы · веб-проект

Опубликованная версия: https://majestic-blini-b6fb7a.netlify.app/ 
Исходники: `main` (публичная версия) и `develop` (разработка). Слияние в `main` должно происходить только после тестов и проверки на телефоне.

## Что уже сделано
- Бесплатный интерактивный калькулятор и символические интерпретации 22 арканов.
- PDF-образец из 3 страниц, без платного полного содержания.
- Описание полного отчёта за **550 ₽**, кнопка оплаты намеренно отключена.
- Переносимая статическая сборка: **без Netlify-specific и Yandex-specific кода**.
- Автоматические тесты формул и структуры.

## Структура в develop
- `index.html` — разметка сайта.
- `assets/styles.css` — оформление.
- `src/arcana.mjs` — открытый каталог кратких значений арканов.
- `src/calculator.mjs` — вычисление матрицы, без зависимости от браузера.
- `src/app.mjs` — интерфейс и взаимодействие с калькулятором.
- `src/pdf-preview.mjs` — только бесплатный PDF-образец в браузере.
- `scripts/site.test.mjs` — тесты, выполняемые локально.
- `server/order-domain.mjs` — безопасные правила будущих заказов, цена 550 ₽ и проверка подтверждённых платежей (без API, ключей и списаний).
- `scripts/order-domain.test.mjs` — тесты от подмены суммы и ложного подтверждения оплаты.
- `scripts/build-static.mjs` — сборка для **любого** статического HTTPS-хостинга.
- `docs/architecture.md` — целевая архитектура, мониторинг, резервирование, стоимость.

## Работа без облачных расходов
Не нужны сторонние пакеты и серверы. Требуется установленный Node.js 22+.

```bash
node --test scripts/*.test.mjs
node scripts/build-static.mjs
```

Готовый сайт появляется в каталоге `dist/`, с HTML, CSS и JS-модулями. Каталог `dist/` можно опубликовать на любом HTTPS-хостинге статических файлов. Изменение в `develop` **не обновляет** действующий сайт.

## Безопасность
- Ни в GitHub, ни в браузере нет секретных ключей, данных покупателей и полной платной библиотеки.
- Приём денег выключен. Позже потребуется отдельно развёрнутый backend с проверкой платежей и приватной выдачей PDF.
- Точные облачные квоты, безопасность и стоимость нужно проверить у выбранного провайдера перед запуском.
- Нумерологические трактовки символические, не научные предсказания.

Сейчас есть **локальный тестовый HTTP-сервер**, база SQLite и офлайн-проверенный модуль чтения статуса платежа через ЮKassa (с подставным HTTP-ответом). Рабочие банковские операции отключены; магазин не развёрнут публично.

В будущем платный backend будет отделён от публичной части и доступен только по защищённым маршрутам. Подробности: [архитектура](docs/architecture.md).

## Приватный прототип платного отчёта
Отдельно от этого публичного репозитория подготовлен редакционный генератор на Python (31 страница). Его исходники и авторские тексты **не находятся здесь**, потому что полный платный контент нельзя публиковать вместе с бесплатным сайтом. `server/report-job.mjs` определяет лишь формат серверного задания, выдаваемого после независимой проверки оплаты. Автоматический выпуск и реальные платежи пока отключены.

## Локальный тестовый магазин (без денег)

Команда `node dev/start-local.mjs` запускает HTTP-демонстратор **только на 127.0.0.1**. Можно создать заказ, имитировать успешную оплату, проверить авторизацию и скачать технический PDF. Тестовые заказы сохраняются в `.matrix-demo-data/`, которая исключена из Git. Если `PRIVATE_PDF_DIR` указывает на распакованный **закрытый** генератор V3, вместо тестового листа используется полноценный локальный PDF.

Это **не магазин для настоящих покупателей**: локальная SQLite уже использует транзакции, но отсутствуют боевой HTTPS/API, реальная ЮKassa, промышленное резервирование и юридически оформленная обработка персональных данных. Настройка не тратит квоты Netlify или Yandex Cloud. Инструкция: [локальный демонстратор](docs/local-demo.md).

Улучшенная иллюстрация главного экрана синхронизирована с веткой `develop`, чтобы последующие обновления не вернули размытую картинку.

## Подтверждённая проверка полного отчёта

Полный локальный путь **заявка → фиктивная оплата → SQLite → приватный генератор V3 → скачивание PDF** проверен с закрытым пакетом на дате 29.02.2000. Проверены PDF-сигнатура, 31 страница и дата на обложке. Приватный пакет не включён в публичный репозиторий.

Ветку `develop` можно обновлять независимо от опубликованного `main`. Все автоматические проверки выполняются без платных облачных вызовов. Код серверной части пока пригоден только для локальной проверки. Инструкция: [локальная проверка](docs/local-demo.md).
