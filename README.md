# Матрица судьбы · веб-проект

Сайт: https://majestic-blini-b6fb7a.netlify.app/

Это существующий проект Netlify, подключённый к публичному GitHub-репозиторию. Основная ветка — `main`. Новые версии `index.html` должны публиковаться через GitHub → Netlify.

## Что сейчас работает
- Бесплатный калькулятор по дате рождения с 20 точками и краткими интерпретациями.
- Светлый архитектурный дизайн, адаптация под мобильный экран.
- Ознакомительный PDF (3 страницы).
- Описание будущего полного отчёта за **550 ₽**, без подписки.

**Приём реальных платежей выключен.** Кнопка полного отчёта не списывает деньги. Платная библиотека и защищённая выдача PDF ещё не реализованы.

## Файлы
- `index.html` — действующий клиентский сайт.
- `scripts/site.test.mjs` — базовые проверки HTML/JavaScript и разграничения доступа.
- `.github/workflows/check-site.yml` — автоматические проверки при обновлении.
- `docs/commerce-plan.md` — план сервера, заказов, оплаты и выдачи полного отчёта.

## Проверка
Установи Node.js 22+ и выполни из корня репозитория:

```bash
node --test scripts/site.test.mjs
```

После изменения кода проверь в Safari: ввод даты, нажатия на арканы, бесплатный PDF, мобильный экран и сообщение об отключённой оплате.

## Безопасность
Никогда не размещай в репозитории API-ключи эквайринга, приватные данные покупателей и полную платную библиотеку. Полный отчёт должен формироваться на защищённом сервере только после подтверждённой оплаты.

Интерпретации носят символический характер и не имеют доказанной предсказательной точности.
