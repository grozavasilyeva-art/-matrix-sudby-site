# Матрица судьбы · веб-проект

Опубликованная версия: https://majestic-blini-b6fb7a.netlify.app/ 
Исходники: `main` (публичная версия) и `develop` (разработка). Слияние в `main` должно происходить только после тестов и проверки на телефоне.

## Что уже сделано
- Бесплатный интерактивный калькулятор и символические интерпретации 22 арканов.
- PDF-образец из 3 страниц, без платного полного содержания.
- Описание полного отчёта за **550 ₽**, кнопка оплаты намеренно отключена.
- Переносимая статическая сборка: **без Netlify-specific и Yandex-specific кода**.
- Автоматические тесты формул и структуры.

## Структура в develop
- `index.html` — разметка сайта.
- `assets/styles.css` — оформление.
- `src/arcana.mjs` — открытый каталог кратких значений арканов.
- `src/calculator.mjs` — вычисление матрицы, без зависимости от браузера.
- `src/app.mjs` — интерфейс и взаимодействие с калькулятором.
- `src/pdf-preview.mjs` — только бесплатный PDF-образец в браузере.
- `scripts/site.test.mjs` — тесты, выполняемые локально.
- `server/order-domain.mjs` — безопасные правила будущих заказов, цена 550 ₽ и проверка подтверждённых платежей (без API, ключей и списаний).
- `scripts/order-domain.test.mjs` — тесты от подмены суммы и ложного подтверждения оплаты.
- `scripts/build-static.mjs` — сборка для **любого** статического HTTPS-хостинга.
- `docs/architecture.md` — целевая архитектура, мониторинг, резервирование, стоимость.

## Работа без облачных расходов
Не нужны сторонние пакеты и серверы. Требуется установленный Node.js 22+.

```bash
node --test scripts/*.test.mjs
node scripts/build-static.mjs
```

Готовый сайт появляется в каталоге `dist/`, с HTML, CSS и JS-модулями. Каталог `dist/` можно опубликовать на любом HTTPS-хостинге статических файлов. Изменение в `develop` **не обновляет** действующий сайт.

## Безопасность
- Ни в GitHub, ни в браузере нет секретных ключей, данных покупателей и полной платной библиотеки.
- Приём денег выключен. Позже потребуется отдельно развёрнутый backend с проверкой платежей и приватной выдачей PDF.
- Точные облачные квоты, безопасность и стоимость нужно проверить у выбранного провайдера перед запуском.
- Нумерологические трактовки символические, не научные предсказания.

Сейчас `server/order-domain.mjs` лишь библиотека бизнес-правил и **не является запущенным сервером**. В ней нет интеграции с ЮKassa. Позже серверный HTTP-слой должен самостоятельно получать подтверждение платежа от провайдера и сохранять заказы в базе.

В будущем платный backend будет отделён от публичной части и доступен только по защищённым маршрутам. Подробности: [архитектура](docs/architecture.md).
