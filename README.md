# Матрица судьбы — сайт

Готовая статическая версия сайта для публикации через GitHub и Netlify.

## Содержимое
- `index.html` — основная страница сайта.

## Как загрузить на GitHub
1. Создайте новый репозиторий на GitHub.
2. Загрузите в него файл `index.html` и этот `README.md`.
3. При необходимости добавляйте новые версии сайта, заменяя `index.html`.

## Как подключить к Netlify
1. Войдите в Netlify.
2. Нажмите **Add new site** → **Import an existing project**.
3. Выберите **GitHub**.
4. Дайте Netlify доступ к вашему репозиторию.
5. Выберите репозиторий с сайтом.
6. Параметры сборки не нужны, так как сайт статический.
7. Publish directory оставьте пустой или `/`.
8. Нажмите **Deploy site**.

## Обновление сайта
После изменения `index.html` в GitHub Netlify сможет автоматически публиковать новую версию.
